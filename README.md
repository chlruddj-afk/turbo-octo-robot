# 단테 세력선 & ISA 농사 노트

112·224·448일선(단테 세력선)과 매집봉으로 종목을 고르고, ISA 배당 농사 매매일지를 남기는 모바일 웹앱입니다.
`index.html` 한 파일이 전부이고, 데이터는 Google Sheets에서 자동으로 읽어옵니다.
차트(세력선) 매력도와 함께 **기업 체력(가치) 매력도**를 나란히 보여줘서, "차트는 좋은데 재무가 어떤지"를 한 화면에서 비교합니다.
v1.4.0부터는 **코스피 대비 상대강도(RS)** 와 **시장 저수지(예비 현금) 신호등** 이 더해집니다.
v1.5.0에서는 **재무 안정성 체크(유보율·최대주주 지분, 김종봉 3원칙)**, **눌림 거래량·위험 경고 배지(김정수)**, **매매일지 최근 3개월 승률·복기 태그**가 더해집니다.
v1.6.0에서는 **업종 태그·52주 신저가 경고·증거금/신용가능 배지**, **같은 업종 중복 몰빵 경고**, **1:1:2:4 피라미드 물타기 계산기(단테 + 주식농사머신 목표가 절반 공식)** 가 더해집니다.
v1.7.0에서는 총 매력도를 **4:4:2 (수급 40 · 세력선 40 · 기업체력 20)** 로 개편했습니다. 수급(단테형 매집·김정수 눌림 거래량·위험경고)과 **단테 밥그릇 1~4번 자리**가 점수에 들어가고, 카드에는 `수급 40% / 세력선 40% / 기업체력 20%` 3줄 막대가 나옵니다.

- W~AA열(PER·PBR·ROE·부채비율·시가총액)은 2026-11-22 네이버금융 조회값으로 채워져 있습니다.
- AB~AD열(RS_20D·RS_60D·상대강도 등급)은 2026-11-20 종가 기준 Yahoo Finance 일봉으로 계산했습니다.
- AE~AH열은 v1.5.0에서 추가했습니다(2026-11-23 조회·계산).
  - `유보율(%)`: 네이버금융 연간 재무의 2025 사업연도 결산 유보율
  - `최대주주지분(%)`: 최대주주 + 특수관계인 합계(와이즈리포트/FnGuide 지분공시 기준)
  - `눌림거래량비율(%)`: 최근 30거래일 최대 매집봉 이후 최근 5거래일 평균 거래량 ÷ 매집봉 거래량 × 100
  - `위험경고`: 없으면 `없음`, 있으면 `장대음봉 주의`·`윗꼬리 음봉 주의`·`단기 2배 급등 주의`를 `·`로 연결
- PER·PBR = 최근 분기 실적(TTM) 기준, ROE·부채비율 = 2025 사업연도 결산 기준.
- AI~AL열은 v1.6.0에서 추가했습니다(2026-11-23 조회).
  - `업종`: 네이버금융 종목 페이지의 업종 분류명(예: 제약, 무선통신서비스, 해운사). 같은 업종이 2개 이상이면 앱이 몰빵 경고를 띄웁니다.
  - `52주신저가대비(%)`: 네이버금융 52주 최저가 대비 현재가 = `(현재가 - 52주최저가) / 52주최저가 × 100`.
  - `52주신저가경고`: `(현재가 - 52주최저가)/52주최저가`가 3% 이내거나 신저가 이탈이면 `52주 신저가 주의`, 아니면 `안전`.
  - `증거금(%)`: 증거금률은 네이버금융에 표기가 없고 **증권사별 값**이라, 확인되는 `신용가능` / `증거금100%` / `미확인` 중 하나로 적습니다(비우면 미확인). `100%`가 들어간 칸은 앱이 ⚠️ 증거금100% 배지로 띄웁니다.
- 비어 있는 열은 `—`(자료 없음)로 표시되고, 점수에서 중립값으로 처리됩니다.
- 시트는 `링크가 있는 사람 누구나 읽기`로 공개돼 있어야 앱이 로그인 없이 읽습니다.

## 매력도 계산

**세력선(차트) 매력도 100점**

```
수렴도 45 + 224선 자리 25 + 매집봉 20 + 배당 보너스 10
```

- 수렴도: 세 선 폭이 1.2%일 때 만점, 벌어질수록 감점
- 224선 자리: 현재가가 224선 -3%~+6% 구간이면 만점

**기업 체력(가치) 매력도 100점**

```
PER 30 + PBR 20 + ROE 25 + 부채비율 15 + 3년 흑자 10
```

| 지표 | 쉬운 말 | 배점 기준 |
|---|---|---|
| PER | 번 돈 대비 주가가 몇 년 치인지 | 5배 이하 만점, 10배까지 감점, 20배 넘으면 급감 |
| PBR | 회사 재산 대비 주가 | 0.5배 이하 만점, 1배 부근 적정, 2배 넘으면 감점 |
| ROE | 내 돈 굴려 얼마나 벌었나 | 15% 이상 만점, 10% 이상 알짜, 5% 아래 감점 |
| 부채비율 | 빚 비율 | 50% 이하 만점, 100% 이하 탄탄, 200% 넘으면 급감 |
| 3년 흑자 | 최근 3년 순이익이 모두 플러스인지 | 3년 연속 +10, 2년 +6, 1년 +3 |

판정: 85점 이상 아주 튼튼 / 70~84 튼튼 / 55~69 보통 / 40~54 주의 / 40 미만 위험.

**코스피 대비 상대강도(RS)**

```
RS_20D = 종목 20거래일 수익률 − 코스피 20거래일 수익률(%p)
RS_60D = 종목 60거래일 수익률 − 코스피 60거래일 수익률(%p)
RS 종합점수 = 50 + 0.6 × RS_20D + 0.4 × RS_60D  (0~100, 50 = 코스피와 같음)
등급 = 강함(60 이상) / 보통(40~59) / 약함(40 미만)
```

**총 매력도 — 4 : 4 : 2**

```
총 매력도 = 수급 × 0.4 + 세력선 × 0.4 + 기업체력 × 0.2 → 100점 만점
```

**수급 100점** (최근 거래일 기준)

```
RS 35 + 눌림 거래량 25 + 매집봉 빈도 12 + 매집 거래량 강도 8
+ 바닥·박스권 매집 10 + 단기 추세 돌파 양봉 10 − 위험경고 감점
```

- RS: `RS 종합점수 ÷ 100 × 35`
- 눌림 거래량: 33% 이하 만점, 60%까지 감점, 100% 초과 0점
- 바닥·박스권 매집: 차트데이터 120봉에서 224선 근처(1.12배 이하) 양봉 + 거래량 20일평균 2배 이상인 날을 세어 6회면 만점
- 단기 추세 돌파 양봉: 최근 20거래일 안에 직전 20일 고가를 거래량 1.2배로 넘긴 양봉이 있고 종가가 그 위면 10점, 밑으로 밀리면 5점
- 위험경고 감점: `장대음봉 주의` −8 · `윗꼬리 음봉 주의` −6 · `단기 2배 급등 주의` −5 · `52주 신저가 주의` −8

**세력선 100점**

```
수렴도 45 + 224선 자리 25 + 매집봉 20 + 배당 보너스 10
+ 정배열 보정(정배열 진입 +6 / 112·224선 위 +3 / 224선 위 +1 / 역배열 −5)
+ 밥그릇 자리 보정
```

|---|---|
| 부채비율 | 100% 이하 |
| 유보율 | 300% 이상 (100~300% 보통, 100% 미만 부족) |
| 최대주주 지분 | 30% 이상 (20~30% 보통, 15~20% 약함, 15% 미만 취약) |

## 눌림 거래량 · 위험 경고 (김정수)

```
눌림 거래량 비율 = 매집봉 이후 최근 5거래일 평균 거래량 ÷ 매집봉 거래량 × 100
33% 이하 → 🟢 눌림 거래량 급감(세력 미이탈) / 33~60% 🟡 보통 / 60% 초과 🔴 거래량 살아있음
```

경고는 최근 차트데이터(120거래일)로 아래 셋을 봅니다.

- 최근 120거래일 저가 대비 +100% 이상 → `단기 2배 급등 주의`
- 최근 10거래일 안 음봉 + 거래량 20일평균 2배 + 몸통 2% 이상 → `장대음봉 주의`
- 최근 10거래일 안 음봉의 윗꼬리가 몸통의 1.5배 이상 + 종가의 2% 이상(거래량 1.2배 이상이거나 윗꼬리 3% 이상) → `윗꼬리 음봉 주의`
