# 단테 세력선 & ISA 농사 노트

112·224·448일선(단테 세력선)과 매집봉으로 종목을 고르고, ISA 배당 농사 매매일지를 남기는 모바일 웹앱입니다.
`index.html` 한 파일이 전부이고, 데이터는 Google Sheets에서 자동으로 읽어옵니다.
차트(세력선) 매력도와 함께 **기업 체력(가치) 매력도**를 나란히 보여줘서, "차트는 좋은데 재무가 어떤지"를 한 화면에서 비교합니다.

## 구글 시트 업데이트

`추천종목` 탭의 열 이름과 순서를 바꾸면 앱이 값을 못 읽습니다. 행만 추가·수정하세요.
헤더 이름으로 열을 찾기 때문에, 아래 이름을 그대로 쓰면 순서가 조금 달라도 됩니다.

```
기준일, 순위, 종목명, 종목코드, 현재가, 112일선, 224일선, 448일선, 수렴도(%),
매집봉(Y/N), 매집봉상세, 배당률(%), 연속배당, 흑자(Y/N), 위험(Y/N), 점수, 등급,
1차매수, 2차매수, 3차매수, 손절가, 한줄근거,
PER, PBR, ROE, 부채비율, 시가총액(억)
```

- W~AA열(PER·PBR·ROE·부채비율·시가총액)은 2026-11-22 네이버금융 조회값으로 채워져 있습니다.
- PER·PBR = 최근 분기 실적(TTM) 기준, ROE·부채비율 = 2025 사업연도 결산 기준.
- 비어 있는 열은 `—`(자료 없음)로 표시되고, 점수에서 중립값으로 처리됩니다.
- 시트는 `링크가 있는 사람 누구나 읽기`로 공개돼 있어야 앱이 로그인 없이 읽습니다.

## 매력도 계산

**세력선(차트) 매력도 100점**

```
수렴도 45 + 224선 자리 25 + 매집봉 20 + 배당 보너스 10
```

- 수렴도: 세 선 폭이 1.2%일 때 만점, 벌어질수록 감점
- 224선 자리: 현재가가 224선 -3%~+6% 구간이면 만점

**기업 체력(가치) 매력도 100점**

```
PER 30 + PBR 20 + ROE 25 + 부채비율 15 + 3년 흑자 10
```

| 지표 | 쉬운 말 | 배점 기준 |
|---|---|---|
| PER | 번 돈 대비 주가가 몇 년 치인지 | 5배 이하 만점, 10배까지 감점, 20배 넘으면 급감 |
| PBR | 회사 재산 대비 주가 | 0.5배 이하 만점, 1배 부근 적정, 2배 넘으면 감점 |
| ROE | 내 돈 굴려 얼마나 벌었나 | 15% 이상 만점, 10% 이상 알짜, 5% 아래 감점 |
| 부채비율 | 빚 비율 | 50% 이하 만점, 100% 이하 탄탄, 200% 넘으면 급감 |
| 3년 흑자 | 최근 3년 순이익이 모두 플러스인지 | 3년 연속 +10, 2년 +6, 1년 +3 |

판정: 85점 이상 아주 튼튼 / 70~84 튼튼 / 55~69 보통 / 40~54 주의 / 40 미만 위험.

카드에는 두 점수가 같이 나오고, 아래처럼 조합을 한 줄로 판정합니다.

- 둘 다 좋음: "차트·재무 둘 다 좋아 — 농사 지을 만한 자리"
- 차트만 좋음: "차트는 좋은데 재무가 약해 — 비중 줄이고 손절 짧게"
- 재무만 좋음: "재무는 알찬데 차트가 아직 — 224선 눌림 기다리기"
- 둘 다 약함: "둘 다 약해 — 지금은 관찰만"

3년 순이익 이력은 앱 안의 내장 표(`FUND_TREND`, 2023→2025 결산)를 쓰고, 표에 없는 종목은 시트의 `흑자(Y/N)`로 대신합니다.
