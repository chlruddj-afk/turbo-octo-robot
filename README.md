# 단테 세력선 & ISA 농사 노트

112·224·448일선(단테 세력선)과 매집봉으로 종목을 고르고, ISA 배당 농사 매매일지를 남기는 모바일 웹앱입니다.
`index.html` 한 파일이 전부이고, 데이터는 Google Sheets에서 자동으로 읽어옵니다.

## 쓰는 곳

- 웹앱: https://chlruddj-afk.github.io/turbo-octo-robot/
- 원본 시트: https://docs.google.com/spreadsheets/d/1NSHukx0xs_ZO3bYTXz4TDIFvjOaxsUkjdIyjsVK_MN8/edit
- 앱이 읽는 CSV: `https://docs.google.com/spreadsheets/d/1NSHukx0xs_ZO3bYTXz4TDIFvjOaxsUkjdIyjsVK_MN8/gviz/tq?tqx=out:csv`

## 화면

| 탭 | 내용 |
|---|---|
| 추천 | 세력선 매력도 게이지, 3개 이동평균 위치 바, 분할 매수·손절가, 매집봉·배당 |
| 매매일지 | 매수/매도 기록, 보유 평단·평가손익, 규칙 기반 복기 코치 |
| ISA | 목표(세후 월 130만 원) 진척, 평가금액·배당수익률, 종목별 배당 |
| 설정 | 시트 연동 상태, 표 붙여넣기, 종목 직접 추가·수정, JSON 백업/복원 |

## 구글 시트 업데이트

`추천종목` 탭의 열 이름과 순서를 바꾸면 앱이 값을 못 읽습니다. 행만 추가·수정하세요.

```
기준일, 순위, 종목명, 종목코드, 현재가, 112일선, 224일선, 448일선, 수렴도(%),
매집봉(Y/N), 매집봉상세, 배당률(%), 연속배당, 흑자(Y/N), 위험(Y/N), 점수, 등급,
1차매수, 2차매수, 3차매수, 손절가, 한줄근거
```

시트는 `링크가 있는 사람 누구나 읽기`로 공개돼 있어야 앱이 로그인 없이 읽습니다.

## 매력도 계산

```
매력도(100) = 수렴도 45 + 224선 자리 25 + 매집봉 20 + 배당 보너스 10
```

- 수렴도: 세 선 폭이 1.2%일 때 만점, 벌어질수록 감점
- 224선 자리: 현재가가 224선 -3%~+6% 구간이면 만점
- 매집봉: 최근 30거래일 매집봉 횟수·최대 배수
- 배당: 배당률 5%를 만점으로 하는 보너스

## 백업

설정 → JSON 내보내기. 매매일지·ISA 설정·직접 고친 종목·마지막 시트 캐시가 한 파일에 담깁니다.
웹앱의 기록은 브라우저(localStorage)에만 저장되므로, 기기를 바꾸기 전에 백업하세요.

## 배포

`main` 브랜치 루트를 그대로 GitHub Pages로 씁니다.
(저장소 Settings → Pages → Build and deployment → Source: **Deploy from a branch**, Branch: **main** / **/(root)**)

`main`에 push하면 1~2분 뒤 위 웹앱 주소에 반영됩니다. `index.html`을 고치면 그대로 다시 배포됩니다.
